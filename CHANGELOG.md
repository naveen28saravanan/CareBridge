# CareBridge One enhanced build - 27 July 2026

## Added

- mandatory protected sign-in before any workspace;
- email patient registration and role-bound email sign-in;
- Google, Facebook and WhatsApp patient sign-in flows;
- prototype WhatsApp OTP and live-provider configuration boundaries;
- session expiry, role lock, account menu, notification centre and secure sign-out;
- dependency-free Node authentication API foundation;
- PBKDF2 password hashing, rate limiting, security headers and development account persistence;
- enhanced warm CareBridge design system and approved-reference HD assets;
- redesigned patient home and mobile navigation pattern;
- interactive full-screen video consultation UI;
- authentication unit tests and button-interaction audit script;
- authentication, gap-closure and manual-setup documentation.

## Improved

- every patient, doctor and operations button now performs an action, navigation, submit workflow or explicit disabled state;
- PWA manifest, service-worker cache version and authentication API cache exclusion;
- accessibility controls now visibly apply large text and high contrast;
- verified-doctor filter and previously static settings toggles now update state;
- traceability matrix and safety documentation.

## External requirements retained

Live Google/Facebook/WhatsApp, video, payments, notifications, encrypted medical storage, clinician validation, hospital capacity feeds, ambulance dispatch, partner contracts, legal/privacy approval and healthcare regulatory determination still require product-owner accounts and accountable external organisations.
